# همراه‌نما (HamrahNama)

یک رابط فارسی و ساده برای **scrcpy** جهت نمایش و کنترل گوشی‌های اندرویدی در ویندوز، با پشتیبانی از اتصال کابلی و بی‌سیم.

## دانلود و اجرا

نسخهٔ موردنظر را از بخش [Releases](https://github.com/abbasmoq/hamrah-nama/releases) دانلود کنید:

- **Portable (پیشنهادی):** همه‌چیز، از جمله نسخه‌های ۳۲ و ۶۴ بیتی scrcpy، داخل بسته قرار دارد.
- **Lite:** حجم کمتری دارد و scrcpy را هنگام اولین استفاده از داخل برنامه دریافت می‌کند.

فایل ZIP را از حالت فشرده خارج کنید و سپس `HamrahNama.exe` را اجرا کنید.

> نسخه‌های آماده به نصب Python یا هیچ کتابخانهٔ پایتونی نیاز ندارند.

## شروع اتصال

1. در گوشی، «گزینه‌های توسعه‌دهنده» و سپس «اشکال‌زدایی USB» را فعال کنید.
2. گوشی را با کابل به رایانه متصل کنید و پیام اجازهٔ اشکال‌زدایی را در گوشی تأیید کنید.
3. در همراه‌نما گوشی را انتخاب کرده و روی «نمایش گوشی» بزنید.

برای اتصال بی‌سیم نیز می‌توانید از بخش «اتصال بی‌سیم» و راهنمای مخصوص نسخهٔ اندروید و برند گوشی در خود برنامه استفاده کنید.

## امکانات

- رابط کاملاً فارسی
- کنترل گوشی با موس و صفحه‌کلید
- اتصال USB و Wi-Fi
- شناسایی گوشی‌های موجود در شبکه
- راهنمای اتصال برای برندهای مختلف
- پشتیبانی از scrcpy نسخهٔ ۳۲ و ۶۴ بیتی
- دریافت و به‌روزرسانی خودکار scrcpy
- تهیهٔ اسکرین‌شات و ضبط ویدیو

## میان‌برها

- `F8`: گرفتن اسکرین‌شات
- `F9`: شروع یا پایان ضبط ویدیو
- کلیک راست: بازگشت به صفحهٔ قبل
- نگه‌داشتن کلیک چپ و حرکت موس: کشیدن، جابه‌جایی و سوایپ
