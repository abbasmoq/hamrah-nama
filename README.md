# همراه‌نما

یک رابط فارسی و ساده برای [scrcpy](https://github.com/Genymobile/scrcpy) با هدف اتصال راحت گوشی‌های اندرویدی از طریق USB و Wi‑Fi.

## امکانات نسخه اولیه

- تشخیص خودکار گوشی، برند، مدل، نسخه اندروید و ABI
- نمایش وضعیت‌های آماده، بدون مجوز و آفلاین به زبان فارسی
- اتصال USB، اتصال TCP/IP و جفت‌سازی بی‌سیم Android 11+
- کشف گوشی‌های قابل اتصال در شبکه از طریق ADB mDNS و پورت استاندارد ۵۵۵۵
- فعال‌سازی و اتصال خودکار Wi‑Fi برای Android 5 تا 10 پس از یک اتصال USB
- راهنمای اختصاصی سامسونگ، شیائومی/ردمی/پوکو، هواوی، آنر، پیکسل، وان‌پلاس، اوپو، ریلمی و موتورولا
- تنظیم کیفیت، FPS، نرخ بیت، صدا، تمام‌صفحه، خاموش‌کردن صفحه و ضبط ویدیو
- پوشه مشترک برای ذخیره عکس و ویدیو با نام‌گذاری خودکار زمان‌دار
- میانبر `F8` برای عکس صفحه و `F9` برای شروع یا توقف ضبط ویدیو
- کنترل خودکار شیائومی/ردمی/پوکو با ماوس سخت‌افزاری UHID، بدون اجبار به حساب Mi
- کلیک راست برای بازگشت و نگه‌داشتن کلیک چپ برای سوایپ، Drag و لمس ممتد
- جفت‌سازی کددار فقط برای Android 11+ است و کد از صفحه Wireless debugging خود گوشی خوانده می‌شود
- پنجره اصلی اندازه ثابت دارد و صفحه آموزش از متن‌های ثابت و راست‌چین تشکیل شده است
- دریافت مستقیم و امن هر دو بسته رسمی `win32` و `win64` با بررسی SHA-256، بدون دانلود تکراری
- بررسی خودکار انتشار جدید از GitHub رسمی و جایگزینی نسخه قدیمی پس از دانلود موفق
- انتخاب خودکار یا دستی نسخه فعال از داخل برنامه

## اجرا از سورس

پیش‌نیاز: Python 3.10 یا جدیدتر با Tkinter.

```powershell
python main.py
```

در اولین اجرا روی «دریافت / بررسی به‌روزرسانی» بزنید. برنامه بسته‌های ۳۲ و ۶۴ بیتی را در `%LOCALAPPDATA%\HamrahNama\tools` قرار می‌دهد. دفعات بعد فقط انتشار جدید یا بستهٔ جاافتاده دریافت می‌شود. سپس می‌توان نسخه فعال را روی خودکار، ۳۲ بیتی یا ۶۴ بیتی گذاشت.

## ساخت فایل اجرایی

```powershell
.\build.ps1
```

خروجی یک بسته Portable در مسیر `dist` است. Python و Tkinter داخل `HamrahNama.exe` قرار می‌گیرند و کاربر نهایی به نصب Python یا کتابخانه دیگری نیاز ندارد. اگر ابزارهای scrcpy قبلاً دریافت شده باشند، پوشه `tools` نیز داخل بسته Portable کپی می‌شود؛ در غیر این صورت برنامه آن‌ها را در اولین دریافت کنار فایل اجرایی ایجاد می‌کند.

برای تولید فایل ۳۲ بیتی، اسکریپت باید با Python 32-bit اجرا شود؛ برای فایل ۶۴ بیتی از Python 64-bit استفاده کنید. نسخه ۳۲ یا ۶۴ بیتی scrcpy به معماری ویندوز مربوط است، نه معماری گوشی.

## سازگاری

- حداقل نسخه گوشی: Android 5 (API 21)
- انتقال صدا: Android 11 به بالا
- معماری گوشی (`armeabi-v7a`، `arm64-v8a` و غیره) توسط ADB تشخیص داده می‌شود؛ سرور scrcpy مستقل از معماری ویندوز است.
- در حالت خودکار، گوشی‌های شیائومی از UHID استفاده می‌کنند. نشانگر ماوس با کلید `Left Alt` بین گوشی و رایانه آزاد یا گرفته می‌شود.
- ویندوز ۳۲ و ۶۴ بیتی با خروجی متناظر پشتیبانی می‌شوند.

scrcpy و ADB محصولات این پروژه نیستند و مجوزهای متن‌باز خودشان را دارند. فایل‌ها فقط از صفحه رسمی Genymobile دریافت می‌شوند.
